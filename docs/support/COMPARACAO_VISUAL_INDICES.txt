CÓDIGO - ANTES vs DEPOIS:
-------------------------

❌ ANTES (Linha ~940 - ERRADO):
```blade
@foreach($availableThemes as $slug => $theme)
    window.themeData['{{ $slug }}'] = {
        slug: '{{ $slug }}',
        name: {!! json_encode($theme['name'] ?? 'Unnamed Theme') !!},
```

PROBLEMA:
- $slug aqui é 0, 1, 2, 3... (índice numérico do array)
- window.themeData['0'], window.themeData['1'], etc
- Quando clica em um tema, procura por 'stelium-sanctuary' mas não encontra (chave é '3')

---

✅ DEPOIS (Linha ~940 - CORRETO):
```blade
@foreach($availableThemes as $index => $theme)
    window.themeData['{{ $theme["slug"] }}'] = {
        slug: '{{ $theme["slug"] }}',
        name: {!! json_encode($theme['name'] ?? 'Unnamed Theme') !!},
```

SOLUÇÃO:
- Mudou $slug para $index (deixa claro que é número)
- Usa $theme["slug"] que contém o slug REAL do tema
- window.themeData['default'], window.themeData['stelium-sanctuary'], etc
- Quando clica em 'stelium-sanctuary', encontra a chave correta!

=================================================================================

POR QUE ISSO ACONTECEU?
-----------------------

O controller retorna um array assim:

```php
[
    0 => [
        'slug' => 'default',
        'name' => 'Padrão Krayin',
        'colors' => [...]
    ],
    1 => [
        'slug' => 'meu-tema',
        'name' => 'Azul Oceano',
        'colors' => [...]
    ],
    2 => [
        'slug' => 'starter',
        'name' => 'Roxo Moderno',
        'colors' => [...]
    ],
    ...
]
```

Quando fazemos `@foreach($availableThemes as $slug => $theme)`:
- $slug = chave do array = 0, 1, 2, 3...
- $theme = valor = ['slug' => 'default', 'name' => '...', ...]

O que precisamos é $theme['slug'] que tem o valor real!

=================================================================================

SOLUÇÃO ALTERNATIVA (se preferir):
----------------------------------

Outra opção seria fazer o controller retornar um array associativo:

```php
// No ThemeController.php, método getAvailableThemes()
protected function getAvailableThemes(): array
{
    $themes = [];
    
    // Garantir que o array usa slugs como chaves
    foreach ($themeDirs as $dir) {
        $slug = basename($dir);
        $themes[$slug] = [  // ← Usar $slug como chave!
            'slug' => $slug,
            'name' => $themeName,
            'colors' => [...]
        ];
    }
    
    return $themes;
}
```

Mas a solução mais rápida é ajustar o Blade para usar $theme["slug"]!
